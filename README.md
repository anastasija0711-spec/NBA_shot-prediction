# 🏀 НБА Аналитички Центар & Машинско Учење (NBA Shot Prediction)

Пројекат за предвиђање успешности шута у НБА лиги коришћењем алгоритма машинског учења (**Random Forest Classifier**) са оптимизацијом хиперпараметара (**GridSearchCV**), напредним инжењерингом својстава (*Feature Engineering*) и интерактивном веб апликацијом на српском језику.

---

## 📁 Структура пројекта

Према структури пројекта у фасцикли `NBA projekat`:

```text
NBA projekat/
│
├── data/
│   ├── shot_logs.csv             # База података о забележеним шутевима
│   └── players.csv               # База података о играчима (висина, позиција, искуство)
│
├── models/
│   ├── nba_shot_model.joblib     # Сачуван оптимизовани Random Forest модел
│   ├── player_id_map.joblib      # Мапа профила играча и заглађене прецизности
│   └── train_model.py            # Скрипта за обраду података, тренинг и GridSearchCV
│
├── .gitignore                    # Игнорисање виртуелног окружења и непотребних фајлова
├── app.py                        # Веб апликација и интерактивни симулатор шута
└── README.md                     # Документација пројекта

⚙️ Технологије и библиотеке

    Python 3.10+

    Pandas & NumPy – чишћење, спајање и обрада података

    Scikit-learn – тренирање модела, RandomForestClassifier, GridSearchCV, матрица конфузије и евалуација

    Joblib – серијализација и учитавање ML модела

    HTML5 / CSS3 / JavaScript – модеран, респонзиван кориснички интерфејс

    Python HTTP Server (http.server, socketserver) – локални веб сервер

🧠 Карактеристике модела (10 ML фактора)

Модел се ослања на 10 својстава:

    SHOT_DIST – Удаљеност од коша

    CLOSE_DEF_DIST – Удаљеност најближег одбрамбеног играча

    SHOT_CLOCK – Преостало време на сату напада

    DRIBBLES – Број дриблинга пре шута

    TOUCH_TIME – Време контакта са лоптом пре шута

    PTS_TYPE – Вредност шута (2 или 3 поена)

    Is_Home – Фактор домаћег терена (1 = домаћи терен, 0 = гостовање)

    Height_Inches – Висина шутера

    Experience_Num – Године искуства шутера у НБА лиги

    career_fg_smoothed – Заглађена каријерна прецизност шутера.

            
         

🚀 Инсталација и покретање
1. Клонирање репозиторијума и инсталација зависности
code Bash

git clone <URL_ТВОГ_РЕПОЗИТОРИЈУМА>
cd "NBA projekat"

# Инсталација потребних Python библиотека:
pip install pandas numpy scikit-learn joblib

2. Тренирање и оптимизација модела (train_model.py)

Ова скрипта учитава CSV податке, врши feature engineering, дели податке на тренинг (80%) и тест (20%) скуп уз стратификацију, а затим покреће GridSearchCV са 3-струком унакрсном валидацијом (3-fold CV) над хиперпараметрима:
code Bash

python models/train_model.py

Шта ради ова скрипта:

    Проналази оптималне параметре (n_estimators, max_depth, min_samples_split).

    Приказује метрике: Accuracy, ROC-AUC skor, Log-Loss, Confusion Matrix и Feature Importance.

    Снима победнички модел у models/nba_shot_model.joblib.

    Снима профиле свих играча у models/player_id_map.joblib.

    Омогућава конзолно (CLI) тестирање предикција уживо.

3. Покретање интерактивног веб студија (app.py)

Након што је модел снимљен, покреће се локални веб студио:
code Bash

python app.py

    Апликација аутоматски отвара прегледач на адреси: http://127.0.0.1:5050

    Уколико се прегледач не отвори сам, кликните на линк исписан у терминалу.

🖥️ Функционалности апликације (app.py)

    Комплетно на ћирилици уз стриктно поштовање српске граматике и падежа (шут/шута/шутева, поен/поена, година/године, сек).

    Метрички систем:

        Дистанце се уносе и приказују у метрима (m), док сервер врши аутоматску конверзију за модел.

    НБА сат за напад:

        Време се уноси у секундама са ознаком сек, уз строгу валидацију граница од 0.1 до 24.0 сек.

    Заштита од погрешног уноса:

        Онемогућен унос негативних бројева и вредности мањих од нуле.

    Анализа играча и дефанзиваца:

        Избор било ког шутера из базе са приказом висине, искуства и каријерног процента.

        Избор дефанзиваца са којима шутер има историјат директних дуела, или претрага било ког другог дефанзивца из лиге.

    Инстант ML предикција:

        Модел у реалном времену израчунава вероватноћу поготка (%), очекиване поене (xP) и даје детаљан текстуални коментар ситуације.
